# Protótipos de UX — PokeBinder

## Direção visual

- Mobile-first.
- Fundo predominantemente branco.
- Vermelho como cor primária de ação e navegação ativa.
- Elementos circulares inspirados na linguagem visual de uma Pokébola.
- Texto escuro e cinzas suaves para hierarquia.
- Cards com cantos arredondados e sombras discretas.
- Interface limpa, amigável e focada nas imagens das cartas.

## Decisões de UX representadas

- A Coleção é o centro da experiência.
- A ação “Adicionar carta” deve estar sempre acessível nas telas de coleção e fichário.
- Quantidades aparecem diretamente nos cards.
- Fichários priorizam uma visualização visual de álbum.
- Navegação inferior é adequada para as áreas principais no celular.
- A interface deve continuar funcional mesmo que as imagens não carreguem.

## Observação

As imagens são referências de direção visual e layout, não especificações pixel-perfect. Textos, ícones, imagens de cartas e componentes finais devem ser implementados de forma nativa no projeto.
