# Spec — Interface Mobile-first

**Modelo:** Terra Médio

## Objetivo

Criar uma experiência simples para uso principalmente em celular.

## Escopo

- Navegação inferior ou equivalente para Coleção, Fichários, Pulls e Perfil.
- Cards de carta com imagem, quantidade e status.
- Grade de fichário com toque para selecionar e mover.
- Formulários adaptados a telas pequenas.
- Estados vazio, carregando, erro e sucesso.
- Responsividade para desktop.
- Acessibilidade básica: foco, labels, contraste e áreas de toque.

## Regras visuais

- Não depender apenas de cor para comunicar estado.
- Imagens devem ter fallback.
- Ações destrutivas exigem confirmação.
- Operações de movimentação devem ter feedback visual.

## Critérios de aceite

- Principais fluxos funcionam em viewport mobile.
- Nenhuma tela exige zoom horizontal.
- Loading e erros não deixam a interface sem feedback.
