# Prompt mestre para subagentes

Você está trabalhando no projeto PokeBinder. Leia `REQUISITOS.md`, `docs/agentes/README.md`, `docs/agentes/00-arquitetura-e-contratos.md` e a spec específica da sua tarefa antes de alterar arquivos.

## Contexto

PokeBinder é uma aplicação mobile-first para coleção e fichários digitais de cartas Pokémon. A coleção representa a posse do usuário; fichários representam a organização visual. Pulls representam compras privadas e podem originar cartas na coleção após confirmação.

## Regras inegociáveis

- Preserve alterações existentes.
- Não use comandos destrutivos.
- Respeite o escopo da spec.
- Não coloque segredos no código.
- Aplique segurança no banco com RLS.
- Não confie apenas em validações do frontend.
- Use valores monetários em centavos inteiros.
- Use transações para alterar alocações de fichário.
- Execute as validações relevantes antes da entrega.

## Entrega

Informe:

1. O que foi implementado ou revisado.
2. Arquivos alterados.
3. Comandos de validação executados e resultados.
4. Decisões técnicas.
5. Pendências, riscos ou dependências para o próximo agente.
